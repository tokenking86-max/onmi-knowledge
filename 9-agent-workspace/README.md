# 9-agent-workspace — Workspace de Agentes de IA

## Propósito

Espacio de trabajo para agentes de IA que operan dentro de ONMI. Incluye memorias, configuraciones, skills y protocolos de coordinación.

## Estructura

| Carpeta/Archivo | Propósito |
|-----------------|-----------|
| `jarvis/` | Workspace de JARVIS (COO) — memoria principal |
| `agents/` | Configuración de subagentes especializados |
| `skills/` | Skills de OpenCode para ONMI |
| `coordination/` | Protocolos de comunicación entre agentes |

## Agentes

| Agente | Rol | Estado |
|--------|-----|--------|
| **JARVIS** | COO — Estrategia, operaciones, coordinación general | ✅ Activo |
| **Arquitecto** | Diseño de soluciones técnicas | 📋 Planificado |
| **Security Officer** | Revisión de seguridad y compliance | 📋 Planificado |
| **Marketing** | Estrategia y ejecución de marketing | 📋 Planificado |
| **Content Writer** | Creación de contenido técnico | 📋 Planificado |
