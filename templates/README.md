# Templates — ONMI

> Plantillas reutilizables para crear documentos estandarizados en ONMI.

---

## Plantillas disponibles

| Plantilla | Propósito |
|-----------|-----------|
| `adr-template.md` | Crear nuevos Architecture Decision Records |
| `document-template.md` | Crear documentos corporativos estándar |
| `agent-memory-template.md` | Crear memorias de agente |

## Cómo usar

1. Copiar la plantilla correspondiente al directorio de destino
2. Completar el frontmatter YAML
3. Desarrollar el contenido siguiendo la estructura
4. Actualizar `status` de `draft` a `review` cuando esté listo para revisión
5. Mover a `active` tras aprobación
