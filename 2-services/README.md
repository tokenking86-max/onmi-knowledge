# 2-services — Catálogo de Servicios

## Propósito

Define el portafolio de servicios de ONMI. Cada servicio tiene su ficha oficial, entregables modelo y plantillas de ejecución.

## Estructura

```
s1-ai-strategy/           → AI Strategy & Technology Roadmap
s2-native-architecture/   → AI-Native Solution Architecture
s3-ai-governance/         → Enterprise AI Governance & Compliance
s4-fintech-audit/         → Fintech Cloud & AI Architecture Audit
s5-agent-blueprint/       → AI Agent & Copilot Architecture Blueprint
s6-quick-win/             → Cloud AI Quick-Win Implementation
```

## Documentos por servicio

| Archivo | Propósito |
|---------|-----------|
| `service-sheet.md` | Ficha oficial: descripción, buyer persona, entregables, precio |
| `deliverables/` | Modelos de entregables (documentos, presentaciones, reports) |
| `templates/` | Plantillas reutilizables para ejecución del servicio |

## Documentos globales

| Archivo | Propósito |
|---------|-----------|
| `catalog.md` | Catálogo completo indexado (visión general) |
| `pricing.md` | Política de precios y condiciones comerciales |
| `bundles.md` | Paquetes agrupados de servicios |
