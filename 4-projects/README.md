# 4-projects — Proyectos

## Propósito

Gestiona la ejecución de proyectos: activos, completados y plantillas de gestión.

## Estructura

| Carpeta/Archivo | Propósito |
|-----------------|-----------|
| `active/` | Proyectos en curso (una subcarpeta por proyecto) |
| `completed/` | Proyectos cerrados (una subcarpeta por proyecto) |
| `templates/` | Plantillas: charter, reporte semanal, cierre |

## Ciclo de vida de un proyecto

```
Lead calificado → Propuesta → Charter aprobado → Ejecución → Cierre → Caso de estudio
```

## Templates disponibles

| Template | Uso |
|----------|-----|
| `project-charter.md` | Documento de inicio — alcance, timeline, equipo, riesgos |
| `weekly-report.md` | Reporte de avance semanal |
| `closeout-report.md` | Informe de cierre — resultados, lecciones aprendidas |
