# 8-knowledge-base — Base de Conocimiento Técnica

## Propósito

Repositorio de conocimiento técnico curado. Sirve como referencia para la ejecución de servicios, diseño de arquitecturas y desarrollo de IP.

## Estructura

| Carpeta | Propósito |
|---------|-----------|
| `cloud/` | Azure, AWS, GCP — patterns, best practices, comparativas |
| `ai-ml/` | IA/ML — LLM architecture, agent patterns, RAG, evaluation |
| `security/` | Seguridad — zero trust, AI security, compliance |
| `fintech/` | Banca/Fintech — regulaciones, arquitectura, pagos |
| `references/` | Referencias externas curadas (libros, papers, herramientas) |

## Principios

1. **No duplicar documentación oficial** — enlazar a fuentes, no copiar
2. **Solo conocimiento curado** — verificado y relevante para ONMI
3. **Contextualizado** — cada documento explica por qué es relevante para ONMI
4. **Vivo** — se actualiza con cada proyecto que genera nuevo conocimiento
