# 1-strategy — Estrategia Corporativa

## Propósito

Define el rumbo de ONMI. Todo lo que se hace en los otros dominios debe alinearse con lo que está definido aquí.

## Contenido

| Documento | Propósito |
|-----------|-----------|
| `vision.md` | Visión, misión, valores, propósito fundacional |
| `market-positioning.md` | Nicho, segmentos objetivo, buyer personas, propuesta de valor |
| `competitive-landscape.md` | Análisis competitivo vivo (competidores directos e indirectos) |
| `roadmap.md` | Roadmap estratégico por trimestres |
| `okrs/` | OKRs por período (un archivo por Q) |
| `decisions/` | ADRs — Architecture Decision Records estratégicos |

## Taxonomía de decisiones

Cada ADR en `decisions/` documenta: contexto, alternativas, decisión tomada, rationale y consecuencias. Es el "por qué" de la estrategia.
