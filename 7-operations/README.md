# 7-operations — Operaciones Internas

## Propósito

Gestiona el funcionamiento interno de ONMI: finanzas, legal, herramientas y procesos operativos.

## Estructura

| Carpeta/Archivo | Propósito |
|-----------------|-----------|
| `finance/` | Presupuestos, gastos, facturación |
| `legal/` | Contratos, términos legales, NDAs |
| `tools/` | Configuración de herramientas (Git, OpenCode, CRM) |
| `playbooks/` | Runbooks operativos (onboarding, kickoff, emergencias) |
| `meetings/` | Minutas y registro de reuniones internas |
