# Playbook: Onboarding de Cliente

> Propósito: Estandarizar el proceso de onboarding de un nuevo cliente en ONMI.

## Fase 1: Kickoff interno

- [ ] Confirmar equipo asignado al proyecto
- [ ] Crear carpeta de proyecto en `4-projects/active/[cliente-proyecto]/`
- [ ] Revisar propuesta aprobada y contrato firmado
- [ ] Completar Project Charter
- [ ] Configurar repositorio (si aplica)
- [ ] Calendarizar reunión de kickoff con cliente

## Fase 2: Kickoff con cliente

- [ ] Presentar equipo ONMI
- [ ] Confirmar objetivos y alcance
- [ ] Definir canales de comunicación
- [ ] Acordar cadencia de reportes
- [ ] Establecer expectativas de entregables
- [ ] Compartir calendario de hitos

## Fase 3: Configuración inicial

- [ ] Obtener accesos necesarios (si aplica)
- [ ] Firmar NDA (si aplica)
- [ ] Configurar repositorio compartido
- [ ] Primera reunión técnica (si el proyecto lo requiere)

## Fase 4: Ejecución

- Seguir el Project Charter y el cronograma acordado
- Reportar avance semanal según template
- Documentar decisiones técnicas como ADRs
