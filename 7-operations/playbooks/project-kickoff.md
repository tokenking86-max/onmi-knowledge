# Playbook: Project Kickoff

> Propósito: Checklist estandarizado para el arranque de cualquier proyecto ONMI.

## Previo al kickoff

- [ ] Propuesta aprobada por el cliente
- [ ] Contrato firmado
- [ ] Project Charter completado y compartido
- [ ] Equipo asignado y notificado
- [ ] Recursos necesarios identificados

## Durante el kickoff (reunión)

### Con el cliente
- [ ] Confirmar alineación de objetivos
- [ ] Revisar entregables y cronograma
- [ ] Definir stakeholders clave
- [ ] Acordar frecuencia de comunicación
- [ ] Establecer canal de comunicación principal
- [ ] Identificar dependencias externas

### Interno ONMI
- [ ] Asignar responsabilidades individuales
- [ ] Revisar riesgos y plan de mitigación
- [ ] Establecer cadencia de check-ins internos
- [ ] Configurar herramientas de seguimiento

## Post-kickoff

- [ ] Enviar minuta de la reunión
- [ ] Compartir cronograma actualizado
- [ ] Primera actividad/sprint planificada
